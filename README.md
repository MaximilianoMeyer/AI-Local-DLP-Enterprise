# AI-Local-DLP-Enterprise

#### The AI Local DLP Enterprise project is a browser extension that integrates with SIEMs, webhooks, and other chats. It's a tool that doesn't block sending natively; the user has control over whether or not to send data to AI agents, but they will be alerted about the type of data. Alerts are sent to the pre-configured environment, informing who sent it, which department, the time, which file, and which AI agent the user used. The idea is to monitor the use of sensitive data with AI agents.
