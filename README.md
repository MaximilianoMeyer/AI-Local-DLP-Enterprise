# AI-Local-DLP-Enterprise

#### O projeto AI Local DLP Enterprise é uma extensão para navegador que possuí integração com SIEMs, webhooks e outros chats.
Uma ferramenta que não bloqueia o envio nativamente, o usuário tem o controle se quer ou não enviar os dados para os agentes de AI, porém, será alertado quanto ao tipo de dados.
Alertas são enviados para o ambiente configurado previamente informando quem foi, qual setor, horario, qual arquivo e qual agente de AI o usuário usou.
A ideia é ter monitoramento quanto ao uso de dados sensíveis em agentes de AI.
